# HTC Blue Angel / i-mate PDA2k — первичный статический разбор

Дата: 15 октября 2026 года.

## Краткий результат

Исследован файл пользователя `Imate_PDA2k_WWE_12200_162_10600_SHIP.exe`.
Это инвентаризация контейнера и таблиц ROM, а НЕ законченный реверс драйверов,
НЕ проверка работоспособности устройства и НЕ готовая альтернативная ОС.

Исходный файл не изменён. EXE/DLL/код прошивки не запускались. Доступа к телефону не было.

- Размер исходного пакета: **27 439 520 байт**.
- MD5: `e75252819ff60d383be59230c3eb75a9`.
- SHA-256: `ac59e03898d559d50a5f16c58c7ed0f7596a89138dd72a769f6fe5eb627e46c3`.
- Встроенный CAB: смещение `0x4855d`, размер **27 143 235 байт**.
- Из CAB извлечены 8 ожидаемых файлов без ошибки распаковки. Их хеши находятся в `extracted_manifest.json`.
- Снято внешнее XOR-кодирование трёх NBF. Это не означает, что все внутренние форматы и сжатие исследованы.
- В основной системе разобраны **14 областей ROMHDR**, **306 записей модулей** и **662 файловые записи**.
  Это количество записей таблиц, а не количество драйверов и не полная инвентаризация памяти телефона.

## Ограничения выполненного анализа

1. Первый участок с сигнатурой по смещению `0xc0` и указателем `0x9006e000`
   не входит в поддержанное здесь отображение основной ОС `0x80000000`.
   Он помечен как исключённый, а не объявлен разобранным загрузчиком.
2. Сжатые файловые объекты не распакованы в отдельные DLL/EXE.
3. XIP-модули не восстановлены в обычные PE-файлы; их E32/O32-адреса только занесены в каталог.
4. Декомпиляция драйверов, восстановление протоколов и реестра не выполнялись.
5. Внутренний формат радиопрошивки не разобран. Снято только внешнее XOR-кодирование.
6. Обновление ROM не исследовалось как полный дамп всех микросхем, калибровок и состояния конкретного телефона.
7. Нет аппаратных тестов, подтверждённой совместимости собственной ОС или проверки её энергопотребления.

## Как воспроизвести

`inspect_blueangel.py` использует Python 3.10+ и системную библиотеку `libarchive` с поддержкой CAB.
Скрипт проверен в Linux. Нативный запуск под Windows не проверен; для такого же окружения подходит Linux/WSL
при наличии указанных зависимостей. В скрипте нет загрузки программ из интернета, запуска EXE,
команд прошивки, доступа к USB или операций с аппаратными регистрами.

```sh
python3 inspect_blueangel.py "/путь/Imate_PDA2k_WWE_12200_162_10600_SHIP.exe" "/путь/новая_папка_результатов"
```

Папка результатов должна быть новой: существующий каталог скрипт не перезаписывает.
Поддержан только этот конкретный пакет: проверяются MD5 и SHA-256.
Результаты: извлечённый CAB, восемь его файлов, три образа после снятия внешнего XOR,
JSON-манифесты и каталог ROM. Файлы прошивки не включены в этот набор материалов.

## Следующая проверяемая цель

Выбрать один небольшой драйвер, например `QwertyKey.dll`: проверить формат сжатия,
извлечь PE, восстановить импорты/экспорты и зависимости, сопоставить код с доступными
описаниями платы и затем проверить предполагаемый интерфейс на работающем устройстве.
Это даёт эталонный цикл анализа для остальных подсистем.

Для телефонной части параллельная цель — определить границы ответственности
`ril.dll`, `rilgsm.dll`, `serial_cmd.dll` и `HTC_CMD.dll`, а НЕ заранее объявить установленной
их точную цепочку вызовов.
