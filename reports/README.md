# Evidence presentation copies

The text reports in this public tree are selected local engineering evidence. Workspace prefixes, personal hostnames and ephemeral QMP socket locations are normalized to placeholders by `scripts/export-public.py`. These are presentation copies, not byte-identical raw host logs.

Guest UART bytes, machine instructions, CPU/memory observations and reported guest-image hashes are retained. A normalized report's own SHA-256 differs from the raw local report. No manufacturer binaries, physical-device trace, photos or personal history are included.
